Search

Files

Code

Python, Node, or browser checks inside Docker.

Git

Commit locally. Push only after an exact approval.

Course constraints02

Method · control loop

The model chooses. The gateway executes.

1. PlanA lead agent emits a task graph. The server checks roles, tools, and dependencies.
→
2. ActThe assignee returns one JSON action: tool, message, ask_human, review, or publish.
→
3. GateAllowlist, schema, budget, SHA binding, and human approval run before any side effect.
→
4. ReceiptThe real tool result is stored. A written file is not success until it is published and checked.

What “done” means

done, partial, and failed stay distinct. A ZIP, a long reply, or a green private test cannot promote a task by itself.

What the human sees

Ambiguous questions and critical writes pause the run. Approval is bound to the exact file hash, remote, branch, and commit.

backend/teams.py04

Method · isolation and handoff

Private files. Explicit copies. No shared shell.

Workspace

Each agent and run gets workspaces/<agent>/<run>. Hidden paths and parent traversal are rejected. imports/ is read-only.

Docker

code.run and code.test start a network-off container. Python uses python:3.11-alpine. Browser checks use a pinned Chromium image. No host fallback.

Artifacts

Cross-agent delivery is an immutable snapshot plus a grant. The receiver reads the import copy and checks SHA-256. Private edits are not the published bytes.

Human gates

  • New file.write proceeds. Overwrite, patch, and delete wait.
  • git.push must match the configured HTTPS remote, fixed branch, and current commit.
  • ask_human is a platform action, not a model feature. No guessed answer is filled in.

Search is not evidence

web.search returns discovery links only. web.fetch stores the delivered text as a same-agent snapshot. A title cannot be cited as a fetched body.

backend/sandbox.py · backend/artifacts.py05

Method · memory and measurement

Learning is a ledger, not a weight update.

What gets remembered

  • Per-owner memory for private chat, group chat, and explicit shares.
  • Failures become candidate lessons. A later task may retrieve them.
  • A candidate stays unconfirmed until a later run shows it was used and the outcome supports it.

What gets counted

  • Subtask status and overall status, kept separate from product quality.
  • Wall time, model calls, and reported tokens.
  • Acceptance is tied to the revision and the artifact hash under review.

Offline regression before R13: 951 tests passed, 0 failed, 0 skipped, 330.9 seconds, with Docker browser and agent checks enabled.

Reflection · what worked

The gate kept a false pass from looking finished.

  • All six cases produced the intended kind of artifact: app, dashboard, article, fact-check, portfolio, HTML slides.
  • N1 and F1 closed as done with formal packages. N1’s checker actually read three official pages.
  • Private tests did not silently become acceptance. S2’s failing QA run was on the reviewer’s own dashboard.js.
  • F2’s reviewed HTML, CSS, JS, and README matched the formal package byte for byte. The missing review was named instead of waived.
  • Search links, file hashes, and tool receipts stayed inspectable after the run.

S1 used almost the whole 45 minutes. N1 finished a publishable pack in 20 minutes.

Reflection · what did not

The same bytes were tested, reviewed, and handed off too late.

Process

  • S1 had a candidate at minute 4.5 and then spent the rest on repeated browser calls. QA never opened the browser.
  • N2’s reviewer had read the new article and still filed the old rework. Packaging was skipped.
  • F2’s subtasks were done and the run stayed partial, because notes added at packaging had no review.
  • No mid-run reassignment was recorded. Memory retrieval did not change a later decision in this round.

Product

  • S1 and S2 can overwrite stored bookings when a read fails or two tabs submit.
  • N1 is shorter than the requester’s about-800-word preference and misses a closed registration.
  • N2 lacks a detector version and over-generalizes “not reliable” into “no evidential value”.
  • F1 uses a long-bond yield for short cash and does not prove the 5% single-company cap through fund holdings.
  • App-level git.push was not exercised on a real remote in this round.

Reflection · what we learned

Bind the test to the bytes you intend to ship.

Version before verdict

A review or browser run must name the artifact hashes it actually opened. A mismatch is feedback, not another silent pass.

Leave a window

The producer cannot keep the wall clock until the last minute. Downstream QA needs a scheduled share of the same 45 minutes.

Close the package

Files added after the last review need a small extra review. Unchanged files can reuse the old evidence.

The harness can make a weak choice look reasonable

Omitted file bodies, a progress receipt that treats another read as progress, and a token reservation equal to the provider’s maximum output all pushed agents to repeat work or stop early. The next change is in those checks, not in a longer prompt. Memory still needs an on/off comparison on the same tasks before we claim that agents learned.
