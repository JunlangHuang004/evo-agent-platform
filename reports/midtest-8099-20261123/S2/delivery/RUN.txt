Open app/index.html in a modern browser (no server/build/network needed). Use sections 1-3 to check availability, book, and cancel rooms; data persists in localStorage. Scroll to section 4 'Manager dashboard', pick From/To dates (defaults to current month-to-date), and the dashboard renders immediately: headline summary (total bookings, reserved hours, cancellations, cancellation rate, busiest day/time), five bar charts (bookings per room, reserved hours per room, bookings per weekday, bookings per 30-min start slot, cancellations per room), a per-room summary table sorted by bookings, and an allocation hint naming most/least used rooms. From>To shows an inline error with no charts; an empty range shows an empty-state message. Cancellations are counted from the additive log key meetingRoomBookings.cancellations.v1 written by the cancel path (absent => 0).
