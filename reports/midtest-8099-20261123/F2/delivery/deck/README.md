# Semiconductor Deck — Usage Notes

**Deliverable:** `index.html` — self-contained HTML slide deck (10 slides), opens in any modern browser.

## How to present
1. Open `index.html` in a browser (double-click, or `open index.html`).
2. Navigate: **→ / Space / PageDown** = next slide; **← / PageUp** = previous; **Home / End** = first / last. On-screen **Prev / Next** buttons also work.
3. A progress bar and slide counter (bottom-right) show position.

## Files
- `index.html` — slide markup (entrypoint)
- `styles.css` — presentation styling
- `app.js` — keyboard/button navigation
- `slides.md` — slide content plan (source of truth)

## Content coverage
- Outlook: demand drivers, supply & geopolitics, valuation & market dynamics
- Investment implications: bottleneck ownership, diversification, sensitivity, entry staging, power factor
- Key risks: ROI, power, innovation/pricing, geopolitics, valuation
- Scenarios (illustrative, not forecasts) and explicit evidence gaps
